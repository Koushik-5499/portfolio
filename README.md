# Premium Futuristic AI Engineer Portfolio

A cutting-edge portfolio website built with Next.js 16, featuring cyberpunk aesthetics, glassmorphism design, and smooth animations.

## 🚀 Features

- **Premium Design**: Dark cyberpunk theme with glassmorphism effects
- **Smooth Animations**: Powered by Framer Motion
- **Holographic Background**: 3D effects and floating elements
- **Typewriter Effect**: Dynamic text animations
- **Achievement Dashboard**: Animated counters and metrics
- **Featured Project Showcase**: FASTPARK as hero project
- **Tech Arsenal**: Interactive skill cards with progress bars
- **Custom Cursor**: Futuristic cursor design
- **Loading Screen**: Premium loading animation
- **Scroll Progress Bar**: Visual scroll indicator
- **Particle Background**: Animated particle system
- **Fully Responsive**: Mobile-first design
- **SEO Optimized**: Meta tags and semantic HTML

## 🛠️ Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **3D Graphics**: Three.js, React Three Fiber
- **Icons**: Lucide React
- **Type Animation**: react-type-animation
- **Counter Animation**: react-countup

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎨 Customization

### Update Personal Information

1. **Hero Section** (`src/components/Hero.tsx`):
   - Update name, tagline, and social links
   - Modify typewriter animation text

2. **About Section** (`src/components/About.tsx`):
   - Update bio, education, and mission statement

3. **Projects** (`src/components/Projects.tsx`):
   - Add/modify project details
   - Update images in `/public/assets/`

4. **Skills** (`src/components/Skills.tsx`):
   - Update skill categories and proficiency levels

5. **Achievements** (`src/components/Achievements.tsx`):
   - Update metrics and hackathon details

6. **Contact** (`src/components/Contact.tsx`):
   - Update email, location, and social links

### Update Resume

Replace `/public/assets/Koushik_S_Resume.docx` with your resume file.

### Update Images

Place your images in `/public/assets/`:
- `avatar.png` - Profile picture
- `holographic-bg.png` - Background image
- `project-fastpark.png` - FASTPARK project image
- `project-election.png` - Election Assistant project image
